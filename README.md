## 🌟 لماذا "لسان"؟

معظم تطبيقات تعلّم اللغات الحالية تكتفي بجعلك تكرر كلمات معزولة لجمع النقاط. **"لسان"** يُدخلك في سيناريوهات واقعية تفاعلية: طلب قهوة، مقابلة عمل، استئجار سيارة، والتحدث مع شخصيات افتراضية تعمل بالذكاء الاصطناعي لتحليل نطقك، ثقتك، وسرعة كلامك.

---

## 🚀 الميزات الرئيسية (24 ميزة مكتملة)

### 1️⃣ التجربة الأساسية والغمر اللغوي
* **1. Dashboard تفاعلية:** متابعة الأيام المتتالية 🔥، المستوى الحالي (A1-C2)، كلمة اليوم العميقة، وجملة اليوم.
* **2. اختبار تحديد المستوى الذكي:** تقييم شامل (قراءة، استماع، قواعد، ومحادثة صوتية) مع توليد خريطة طريق (Roadmap) مخصصة.
* **19. وضع السفر بدون إنترنت (Offline Mode):** بطاقات طوارئ صوتية جاهزة للمطار، الفندق، المطعم، والتاكسي.
* **24. وضع الغمر الشامل (Total Immersion):** تحويل واجهة التطبيق تدريجياً إلى اللغة المستهدفة + قصص تفاعلية متعددة المسارات + ترجمة الكاميرا.

### 2️⃣ التعلم بالصوت والمحادثة الذكية
* **7. التقييم الذكي للنطق:** تحليل دقة الحروف، سرعة الكلام (WPM)، مستوى الثقة، والتردد باستخدام الذكاء الاصطناعي.
* **8. غرف المحادثة الواقعية (AI Roleplay):** تحدث صوتياً مع الذكاء الاصطناعي بدوري: موظف استقبال، طبيب، مدير توظيف، أو صديق.
* **16. مقارنة الموجات الصوتية (Visual Waveform):** تسجيل نطقك ومقارنة شكل موجتك الصوتية بالنطق المرجعي لأصحاب اللغة.

### 3️⃣ المفردات والجمل المتقدمة
* **3. بطاقات الكلمات العميقة:** 12 تفصيلة لكل كلمة (نطق بطيء، أصل تاريخي، عامي ورسمي، أخطاء شائعة، وطريقة التذكر).
* **4. جمل المواقف اليومية:** مقسمة بالقطاعات الحيوية مع شرح وتفكيك التعبيرات.
* **11. المراجعة الذكية بـ SRS:** خوارزمية التكرار المتباعد (Spaced Repetition) لتثبيت الكلمات المنسية.
* **15. القاموس الذكي الشامل:** بحث فوري مع استخراج المرادفات والأضداد والأمثلة.

### 4️⃣ المهارات الأكاديمية والتفاعلية
* **5. مكتبة الصوتيات والبودكاست:** مشغل بمستويات سرعة (0.5x - 2.0x) وإظهار/إخفاء النص.
* **6. القارئ التفاعلي:** اضغط على أي كلمة داخل النصوص للحصول على معناها ونطقها فوراً.
* **9. معلم الكتابة والمقالات:** مصحح ذكي يمنحك درجة /100 ويكتشف الأخطاء مع اقتراح صياغة بليغة.
* **10. شرح القواعد البصري:** خطوط زمنية (Timelines) بصرية تبسط أزمنة القواعد دون تعقيد.

### 5️⃣ الميديا والألعاب والتنافس
* **12. مركز الألعاب:** ترتيب الكلمات، تحديات كتابة السرعة، وعجلة الحظ.
* **13. لوائح الصدارة التنافسية:** ترتيب عالمي، ترتيب على مستوى الدولة، وترتيب الجامعة (مثل جامعة عين شمس).
* **14. لوحة الإنجازات والأوسمة:** فتح أوسمة رقمية عند تحقيق إنجازات حقيقية.
* **17. التعلم بمشاهد الأفلام:** مقاطع سينمائية قصيرة مع خاصية "تمثيل المشهد".
* **18. التعلم بالأغاني:** كلمات تفاعلية متزامنة مع تحدي ملء الفراغات الصوتية.

### 6️⃣ المجتمع والإدارة
* **20. مجتمع المتعلمين:** طرح الأسئلة، الإجابات، وتصحيح كتابات الآخرين.
* **21. لوحة الإحصائيات الشاملة:** رسم بياني لقياس تطور المهارات الخمس وساعات التعلم.
* **22. مدير التنزيلات الأوفلاين:** تحميل الدروس والمحتوى للعمل بدون شبكة.
* **23. لوحة تحكم المشرف (Admin Panel):** إمكانية إضافة دروس، رفع صوتيات، وإرسال إشعارات لحظية (Push Notifications).

## 🛠️ المعمارية البرمجية (Architecture)

تم بناء المشروع باستخدام معمارية **Vanilla Dynamic Modules** بدون معقدات أو برامج تجميع خارجية (No-Build Step) لضمان السرعة الأقصى وسهولة التعديل:

* **Frontend Framework:** HTML5 + Tailwind CSS v3 (CDN)
* **Design System:** Dark Mode / Glassmorphic UI Custom Aesthetics
* **Icons:** Lucide Icons
* **PWA Engine:** Web App Manifest + Service Worker (`sw.js`)
* **Audio Synthesis:** Web Speech Synthesis API
* **Microphone Processing:** Web MediaRecorder API
